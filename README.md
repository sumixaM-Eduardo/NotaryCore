# NotaryCore

Sistema para gerenciamento e automação de processos cartorários.

## Objetivos

- Gerenciar pessoas físicas e jurídicas
- Gerenciar protocolos
- Registrar atos
- Associar partes aos atos
- Automatizar a geração de minutas
- Reduzir trabalho manual dos escreventes

## Stack

Backend:
- C#
- .NET
- ASP.NET Core
- Entity Framework Core

Banco:
- PostgreSQL

Frontend:
- TypeScript
- React
